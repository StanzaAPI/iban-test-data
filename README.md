# IBAN Test Data

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23076178.svg)](https://doi.org/10.5281/zenodo.23076178)

One valid test IBAN per country, generated deterministically and checked with the ISO 7064 MOD-97 algorithm. None is a real account.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

DOI: [10.5281/zenodo.23076178](https://doi.org/10.5281/zenodo.23076178)

## Files

- `iban-small.json`
- `iban-small.csv`
- `iban-medium.json`
- `iban-medium.csv`
- `iban-large.json`
- `iban-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
